**작성일**: 2026-10-20  
**문서 위치**: `dev_log/fistr_element_strategy_and_conforming_benchmark_plan_20261020.md`  
**대상 솔버**: FrontISTR v5.4+ (SMP OpenBLAS / PARDISO)  
**핵심 과제**: 180° 디스플레이 박막 폴딩(PET 50µm / PSA 30µm)에서 FrontISTR의 전단 잠김 및 체적 잠김 동시 극복

## 1. 배경 및 문제의 본질 (Problem Statement)

디스플레이 폴딩 해석에서 상하 탄성 박막(PET $50\,\mu\text{m}$, $E=4000\,\text{MPa}$)과 중간 점착층(PSA $30\,\mu\text{m}$, 비압축성 $\nu=0.499$)의 적층 구조를 FrontISTR 기본 8절점 육면체(`Hex-361 FI`)로 해석했을 때, **MacNeal-Harder 굽힘 기준 93.34%에 달하는 극심한 전단 잠김(Shear Locking)**이 발생하여 반력 모멘트가 이론치($0.2317\,\text{N}\cdot\text{mm}$) 대비 **7.5배 폭등($1.738 \sim 5.4\,\text{N}\cdot\text{mm}$)**하는 현상이 확인되었습니다.

이를 해결하기 위해 심층 논의된 6가지 기술적 접근법의 장단점을 정리하고, FrontISTR 환경에서 가장 확실하고 결함이 없는 **최종 선정안(2차-1차 적합 세분화 메쉬 기법)**의 기구학적 설계 및 검증 계획을 수립합니다.

### 최종안(방법 6)에 이르게 된 결정적 이유
1. **FrontISTR의 소스 코드 한계 우회**:
   - FrontISTR는 2차 u-P 요소(`elemopt362`)가 주석 처리되어 없고, 1차 비적합 모드(`361 IC`)는 대변형에서 차단되어 있습니다.
   - 따라서 **"PET는 2차 곡률로 전단잠김을 깨고, PSA는 1차 u-P로 체적잠김을 깬다"**는 역할 분담이 유일한 해법입니다.
2. **TIED 접촉의 수치적 비용 회피**:
   - `TIED` 접촉을 걸면 $10^6$ 페널티 상수로 인해 강성 행렬 조건수가 악화되어 뉴턴 반복수가 폭증합니다.
   - **PSA 메쉬를 길이 방향으로 정확히 2배 분할**하면, PET의 모서리 중간 노드(Mid-side node)가 PSA 두 요소가 만나는 코너 노드와 **비트 단위로 1:1 일치**하게 되어, TIE 구속 없이 순수 단일 연속체(Conforming Mesh)로 풀 수 있습니다.

## 3. 단위 깊이(Unit Depth, $nz=1$) 3D 테스트 모델 기구학 명세

### 3.1 레이어 스택업 및 요소 타입
* **Top Layer**: PET ($t = 0.05\,\text{mm} = 50\,\mu\text{m}$), $E = 4000\,\text{MPa}, \nu = 0.3$, **요소: `362` (20-절점 2차 육면체)**, 두께 $ny = 1$
* **Middle Layer**: PSA ($t = 0.03\,\text{mm} = 30\,\mu\text{m}$), $E = 2.0\,\text{MPa}, \nu = 0.499$, **요소: `361` with `FORM361=UP` (8-절점 1차 u-P 육면체)**, 두께 $ny = 1$
* **Bottom Layer**: PET ($t = 0.05\,\text{mm} = 50\,\mu\text{m}$), $E = 4000\,\text{MPa}, \nu = 0.3$, **요소: `362` (20-절점 2차 육면체)**, 두께 $ny = 1$
* **총 모델 두께**: $t_{\text{total}} = 0.05 + 0.03 + 0.05 = 0.13\,\text{mm} = 130\,\mu\text{m}$
* **모델 길이**: $L = 5.0\,\text{mm}$ (또는 힌지 굽힘 $R = 1.5\,\text{mm}$ 반원 호 길이 $L = \pi R \approx 4.71\,\text{mm}$)
* **단위 폭(Depth)**: $W = 1.0\,\text{mm}$ ($z \in [0.0, 1.0]$)

### 3.2 격자 분할 및 절점 일치 토폴로지 (Mesh Topology)
```text
Z 방향 (폭 1.0mm) 단면 토폴로지:
  PET (2차 362):  nz = 1  --> Z 절점 3개:  z = 0.0, 0.5, 1.0 mm (코너 2개 + 변중간 1개)
  PSA (1차 361):  nz = 2  --> Z 절점 3개:  z = 0.0, 0.5, 1.0 mm (요소 2개 코너 절점)

X 방향 (길이 L) 계면 토폴로지:
  PET (2차 362):  요소 크기 Delta_X = 2 * L_elem  --> 3개 절점 (0, L_elem, 2*L_elem)
  PSA (1차 361):  요소 크기 Delta_X = 1 * L_elem  --> 3개 절점 (0, L_elem, 2*L_elem)
```
> **검증**: $X$ 방향과 $Z$ 방향 모두에서 PET의 중간 절점이 PSA의 코너 절점과 좌표가 완벽히 일치하여, **Hanging Node가 0개인 단일 연속체 메쉬**가 형성됩니다.

## 4. 검증 목표 및 정량적 합격 판정 기준 (Acceptance Criteria)

1. **Hanging Node 검사**:
   - 메쉬 생성 후 계면 절점 전수 검사: 짝이 없는 고립 절점 수 $= 0$ 개.
2. **단면 반력 모멘트($M_{\text{root}}$) 검증 (20° 또는 순수 굽힘 벤치마크)**:
   - 기존 FrontISTR `Hex-361 FI` 1층: $M \approx 5.4\,\text{N}\cdot\text{mm}$ (7.5배 폭등, 실패)
   - **적합 세분화 모델 (`362` + `361 UP`) 목표**: $M_{\text{theory}} = 0.2317\,\text{N}\cdot\text{mm}$ 대비 **오차 $< 5\%$ 이내 진입** ($M \approx 0.22 \sim 0.24\,\text{N}\cdot\text{mm}$).
3. **PSA 층간 슬립(Shear Slip) 검증**:
   - 비압축성 PSA 내부 전단각 $\gamma_{xz}$가 구속되지 않고 정상 발생하여, 중립면 슬립량 $\Delta u_x \approx 200\,\mu\text{m}$ 정상 해방.
4. **수렴성 및 계산 시간**:
   - TIED 접촉 대비 컷백 없이 스텝당 뉴턴 반복 수 $\le 6$회 이내 빠른 수렴.

```markdown

"단위 깊이(nz=1) 2차-1차 적합 메쉬(Conforming Mesh) 벤치마크" 스크립트를 구현하라.

### 1. 대상 모델 및 스택업
- 총 길이 L = 5.0 mm, 폭 W = 1.0 mm (Z in [0, 1])
- Top Layer: PET (t = 0.05 mm, E = 4000 MPa, nu = 0.3), FrontISTR 요소 `362` (20절점 2차 육면체)
- Mid Layer: PSA (t = 0.03 mm, E = 2.0 MPa, nu = 0.499), FrontISTR 요소 `361` with `FORM361=UP` (1차 u-P)
- Bottom Layer: PET (t = 0.05 mm, E = 4000 MPa, nu = 0.3), FrontISTR 요소 `362` (20절점 2차 육면체)

### 2. 메쉬 적합 세분화(Conforming Subdivision) 구현 규칙 (Hanging Node 0개 원칙)
- PET 층(2차 요소)은 X방향 길이 분할수 Nx_pet = 20, Z방향 분할수 Nz_pet = 1 (2차이므로 면당 8개 절점)
- PSA 층(1차 요소)은 X방향 분할수 Nx_psa = 40 (2배), Z방향 분할수 Nz_psa = 2 (2배)로 분할
- PET 아랫면의 모서리 중간 노드(Mid-side node)와 코너 노드가 PSA 윗면의 1차 요소 코너 노드와 
  정확히 동일한 (X, Z) 좌표를 갖도록 절점 번호(Node ID)를 1:1로 공유(Shared Nodes)할 것.
- TIE 접촉이나 MPC 구속을 일체 쓰지 말고, 단일 HEC-MW 그리드로 직접 조립할 것.

### 3. FrontISTR 제어 파일 (.cnt) 설정
- `!SOLUTION, TYPE=NLSTATIC`
- `!PARAM, NLGEOM=ON`
- PSA 섹션에 `!SECTION_CONTROL, SECNUM=2, FORM361=UP` 명시
- 하중 조건: 일단 고정(X=0), 타단(X=L)에 20도 순수 굽힘 강제 회전 변위 처방

- 기존 361 FI 결과(5.4 N*mm) 대비 전단 잠김 소거 여부를 정량적으로 보고할 것.
```
