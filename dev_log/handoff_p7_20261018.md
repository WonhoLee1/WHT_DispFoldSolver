## 2. 겹침 주의 (P3 소유 파일)

`dynamic2d.py`, `dynamic3d.py`, `step_executor.py`는 P3가 수정 중이다. 내 변경은 각각 독립된 작은 블록이다.
- `solve()` 시그니처 끝에 `restart` 인자 추가 (3D, 2D)
- `initial_acceleration` 조건에 `restart is None and` 추가 (3D, 2D)
- 루프 직전 재개 블록, 수렴 직후 기록 쓰기 블록
- 2D: `elem_sdvs` 할당 3줄
- `step_executor.execute_step`: 인자 1개와 `solve` 호출의 kwargs

P3가 `solve()` 또는 `execute_step`의 시그니처를 바꿨다면 `restart` 인자만 옮기면 된다.

## 4. 동작 변화

1. **C3D8 탄소성이 이제 이력을 가짐 (N1).** NLGEOM 켬·끔 모두. 단조 하중 결과는 같고, 제하·반복 하중 결과가 달라진다(더 정확). C3D8 소성을 쓰는 기존 결과와 비교하는 벤치마크가 있다면 갱신 필요 (전체 테스트에서는 새 실패 없음).
2. **2D 표형 J2의 SDV가 이제 읽힘 (N2).** CPE4(NLGEOM 끔), CPE4I에서 소성 이력이 생김.
3. `ENGINEERING CONSTANTS`가 C3D20 외 3D 요소에서도 동작. 카탈로그 리팩터로 특이 행렬일 때 `eye*E1` 폴백이 사라지고 예외가 남.
4. 섹션 방향이 걸린 직교이방성 재료는 거부 대신 회전 강성으로 풀림 (RECTANGULAR/COORDINATES). 다른 정의와 2D는 정확한 사유와 함께 거부.
5. **2D 비선형 재료가 이제 거부되거나 올바르게 풀린다.** `CPE4`, `CPE4I`, `CPE4R`, `CPE4H`는 소성·초탄성 재료를 따르고(이전에는 CPE4(NLGEOM), CPE4R, CPE4H가 경고 없이 탄성으로 풀었음), `CPE3`, `CPE6`, `CPE6M`, `CPE8`, `CPE8R`, 축대칭, 트러스는 비선형 재료에서 `NotImplementedError("... linear-elastic-only kernel ...")`. 이 요소들에 소성·초탄성을 쓰던 기존 덱은 이제 오류가 난다 (전체 테스트에서는 해당 사례 없음).
6. **폴더블 프레임워크(`ex1`) 결과가 달라진다**: PET 소성, PSA 초탄성·점탄성이 처음으로 풀이에 들어간다. PSA 체적 상수는 K=2000 MPa(고정 D=0.001)에서 스펙의 8.33 MPa로. 이전 결과와 직접 비교 불가.
7. `*RESTART`는 이제 등록된 키워드(이전: 미등록 경고). 덱에 `*RESTART, WRITE`가 있으면 `execute_inp`가 `<덱 폴더>/<덱 이름>_<step>_<inc>.rst`를 기본으로 쓴다. 원치 않으면 `FREQUENCY=0`.

## 5. 통합자 요청 / 교훈 초안

교훈 초안 (`LESSONS_LEARNED.md`에 반영):
- 테스트의 사전조건 단언이 결함을 먼저 드러냈다: 재시작 테스트가 "SDV가 0보다 크다"를 요구하자, 소성 이력이 저장되지 않는 커널·할당 결함 두 건이 나왔다. 하나의 기능 테스트를 쓸 때 "이 상태가 실제로 쌓이는가"를 먼저 단언하라.
- 요소별 커널이 재료 모델을 부르지 않고 속성 배열의 E, ν로 선형 탄성만 계산하는 경우가 2D에 있으며, 카탈로그가 이를 표시하지 않아 비선형 재료가 조용히 탄성으로 풀린다 (N3). 커널마다 "어떤 재료를 지원하는가"를 카탈로그에 선언하고 거부하게 만들 것.
- 실제 Abaqus 덱 코퍼스가 새 키워드 핸들러의 과잉 엄격함(READ+WRITE 동시, 축약 파라미터, FREQUENCY=0)을 잡았다. 키워드를 추가할 때 `benchmark_inp`에서 그 키워드의 실제 사용 형태를 먼저 모아라.
- 기능이 테스트보다 앞서 구현되면(이번에 두 번) 변이 검사로 테스트가 실제로 실패할 수 있음을 확인하라.

릴리즈 노트 초안:
- keyword: `*RESTART`(WRITE FREQUENCY/OVERLAY, READ STEP/INC/END STEP), `*ORIENTATION` 추가 회전각.
- solver: 재시작 기록 쓰기·읽기, `execute_inp(job, restart_dir, oldjob)`.
- material: 3D 직교이방성 + 재료 방향(RECTANGULAR), C3D8 소성 이력 수정, 2D 표형 J2 SDV 수정.
