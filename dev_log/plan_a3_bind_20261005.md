# A3 — BIND pass: plan (2026-10-05)

Spec row A3 (`impl_spec_inp_pipeline_two_agents_20261005.md`): scoped
case-insensitive symbol tables; every reference resolved in one place;
`regions.py` becomes its backend; no name resolution left in handlers or
solvers; unresolved -> `error` with `Loc`.

## Where binding happens today (inventory, 2026-10-05)

Most keyword handlers store names as strings. The effective binding happens
late and in many places: `Assembly.build_solver_system` (flattening,
`global_nsets` / `ambiguous_names`), `model/regions.py` (strict, raises),
`Model.create_solver*`, `Coupling.bind` / `EquationConstraint.bind`,
`model/interaction.py` (`_resolve_node_ids`, `_resolve_master_faces`), and
per-solver `_resolve_*` in `solver2d/dynamic2d.py` / `solver3d/dynamic3d.py`.

## Design

- `dispsolver/model/bind.py`:
  - `SymbolTable(model)`: case-insensitive tables built from the parsed
    Model -- steps, materials, sections, orientations, amplitudes,
    contact properties, parts, instances, assembly node/element sets and
    surfaces, part sets/surfaces reachable as `INST.NAME`
    (`ASM.INST.NAME` accepted).
  - `resolve(kind, name) -> object`, Abaqus rules: exact or case-folded
    match; qualified names; a bare part-level name only when exactly one
    instance defines it, otherwise `AmbiguousRef`; unknown -> `UnresolvedRef`.
  - `bind_model(model, diagnostics)`: walks every reference-carrying field
    (BC/load region + amplitude + create step, section material /
    orientation / assignment region, contact pair surfaces + interaction,
    tie surfaces, coupling ref/surface, transform nset, output request
    nset/elset, predefined-field region) and reports `unresolved-ref` /
    `ambiguous-ref` (error) with the object's `source_location`.
- The reader calls `bind_model` once, after the last block (forward
  references are legal in Abaqus where the keyword is model data).
- The name-matching core (case fold, qualification, ambiguity) is shared by
  `bind.py` (model space) and `regions.py` (flattened solver space), so the
  two cannot disagree.

## Phases

- **P1 (sonnet):** `bind.py` (SymbolTable + bind_model), reader wiring, tests
  (`tests/test_bind.py`). Validation only -- consumers unchanged. Corpus:
  every new `unresolved-ref` must be classified (deck typo vs binder bug)
  before the baseline is regenerated.
- **P2 (sonnet):** remove the silent fallbacks in the table above (each
  becomes a raise or a binder call); fix the `interaction_properties`
  attribute bug; tests per site.
- **P3 (opus; semantics):** replace the first-match scans with the shared
  core; decide bare-name semantics for *EQUATION / coupling terms.
- Out of scope (A4): records holding resolved handles; StepPlan consumes them.

## P3 decisions (2026-10-05, after reading the scan sites)

All first-match scans resolve through `model/regions.py`
(`resolve_node_region` / `resolve_elem_region`), so they get the same rules
as BCs and loads: qualified `INST.NAME`, a bare part-level name only when one
instance defines it (else an ambiguity error), `ALL`, a bare number only in a
single-instance model, `INST.<n>` otherwise.

- `Coupling.bind` (`constraint.py`): REF NODE is a node label or a one-node
  node set (Abaqus *COUPLING / *RIGID BODY). Today a bare number matches the
  FIRST instance that has that label, and a REF NODE naming an element set
  takes that set's first element's first node -- both go. A node set with
  more than one node is an error (Abaqus: "must contain exactly one node").
  SURFACE resolves as a surface (assembly or `INST.SURF`) or node set; the
  element-set fallback that takes every node of the elements stays only if
  Abaqus allows it (it does not for *COUPLING, SURFACE=: element-based
  surface) -- remove it.
- `EquationConstraint.bind` and the parse-time `_resolve_equation_nodes`
  (`p0_2.py`, first PART that defines the set): a set term resolves at bind
  time through regions (node order = the set's stored order, which is sorted
  -- see `set-order-sorted`), not at parse time against the first part.
- `nodal_transform.py`: transform nset through regions.
- `interaction._resolve_node_ids` / `_resolve_master_faces`: a part surface
  named without an instance resolves only when one instance uses that part;
  "first instance" goes.
- `bind.SymbolTable` and `regions.py` keep separate entry points (model
  space vs flattened space) but the case-fold / qualification / ambiguity
  helper is shared.
