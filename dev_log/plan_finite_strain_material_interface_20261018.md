# 계획: 대변형·대회전에서 PSA·PET·GLASS를 정확히 풀기 (재료-요소 인터페이스)

**작성일**: 2026-10-18
**상태**: 계획 (구현 전). 사용자 결정이 필요한 항목은 §8.
**관련**: `prd_2d_material_wiring_20261018.md` (N6), `abaqus_feature_gap_dispfold_20261018.md` §6, AGENTS.md §4.14~4.18

## 1. 목표

폴더블 접힘에서 세 재료가 각각 겪는 상황을 정확히 풀 수 있게 한다.

| 재료 | 접힘에서 겪는 것 | 요구 |
|---|---|---|
| PSA 점착층 (Arruda-Boyce + Prony, ν≈0.5) | 수백 % 전단, 큰 회전 | 유한변형 초탄성·점탄성, 비압축 잠김 없음 |
| PET (탄소성, 항복 변형률 약 2%) | 굽힘 변형률이 항복과 같은 크기(60 µm, R≈1.5 mm에서 약 2%), 큰 회전, 반복 접힘 | **소성의 정확도와 객관성**, 제하·반복, 소성 변형률 출력 |
| GLASS (UTG, 탄성) | 큰 회전, 변형률 약 2% 이내, 파단 판정에 쓰는 최대 주응력 | 큰 회전 정확도, 현재 형상 기준(Cauchy) 응력 출력 |

핵심 해석: 현재 구조(요소별 co-rotational 프레임 + 국부 소변형 + 소성은 Hencky)는 **큰 회전은 정확히 처리**한다. 문제는 **큰 변형률**이고, 이것이 PET에서 얼마나 문제가 되는지는 아직 모른다. 이 계획은 먼저 그 빈칸을 측정으로 채운 다음 수정 범위를 정한다.

## 3. 원칙

1. **측정이 수정 범위를 정한다.** 접힘에서 각 재료의 최대 국부 신장(ln λ)과 PEEQ를 먼저 재고, 선형 근사의 오차가 허용치를 넘는 곳만 고친다.
2. **재료는 건드리지 않는다.** 디스패치는 이미 올바른 규약(E=GL → PK2, 소성은 Hencky)을 갖고 있다. 고치는 곳은 요소가 재료에 넘기는 변형 척도와 응력을 내적하는 방식이다 (일-공액, AGENTS.md §4.14 F4).
3. **요소는 운동학, 재료는 구성식** (프로젝트 방침). 요소가 실제 F를 만들고 재료는 F 또는 그에서 얻은 변형률을 받는다.
4. **독립 기준으로만 합격**: 닫힌 형식과 레거시 JAX 스택(유한변형 곱셈 소성, Hencky)을 오라클로 쓴다. 이번 세션의 교훈: 시험이 먼저 실패해야 하고, 시험 경로 자체의 결함(현 효과, 헬퍼 버그)을 의심한다.
5. **조용한 오답 금지**: 정확도 범위를 벗어나는 요소·재료 조합은 거부하거나 경고한다 (`elastic_only` 선언과 같은 방식).

## 4. 단계

### 단계 0 — 기준선과 오라클 (측정만, 수정 없음)
- 0-1. `n6-measure` 오차표(초탄성 2D/3D 요소 × 변형 0.001~3.0): 어느 요소가 어느 변형에서 무너지는지.
- 0-2. **PET 소성 오라클 구축**: 닫힌 형식. 일축 변형(F=diag(λ,1,1))에서 Hencky 소성은 로그 변형률 공간에서 소변형 J2와 같으므로 ε→ln λ로 치환한 닫힌 형식이 나온다 (σ=τ/J). 굽힘은 탄성-선형경화 직사각 단면의 모멘트-곡률 닫힌 형식. 추가로 레거시 `material/plastic_jax.py`(곱셈 소성, Hencky)를 수치 오라클로.
- 0-3. **접힘 변형률 조사**: 레거시 ex12(14층, 90°/측 도달)와 `compact_4` 2D 실행에서 층별 최대 |ln λ|, PEEQ, 요소 왜곡을 기록. 이 표가 PET/GLASS에 유한변형 수정이 필요한지 결정한다.
- 0-4. PET 소성 오차 곡선: 위 오라클 대비 현재 요소의 일축 변형·단순 전단 응답을 5%, 10%, 20%, 30%에서.
- 종료 기준: PET·GLASS·PSA 각각의 "필요 변형률 범위"와 "현재 허용 범위"가 표로 있고, 어느 요소가 어디서 벗어나는지 안다.

### 단계 1 — 공통 운동학 부품 (요소 → 재료 인터페이스)
- 국부 변형 구배 `F_loc = I + ∇u_loc`(co-rotational 국부 프레임)와 GL 변형률·로그 변형률·`J`를 계산하는 공통 함수 (`element2d/`, `element3d/`에 하나씩). `CPE4R`의 블록(`cpe4r_numba.py:185-238`)이 템플릿.
- 재료 유형별 변형 척도 선언(`MaterialSpec`처럼 카탈로그에): 초탄성 = GL E(F로부터), 소성 = Hencky(ln U) 또는 현행 소변형, 선형 탄성 = 현행. 이렇게 하면 J2 경로(PET)를 건드리지 않고 초탄성(PSA)만 F 기반으로 바꾼다.
- 일-공액: GL E를 쓰는 요소는 PK2를 `B_L(F)ᵀ`와 `dV₀`로 내적하고 기하 강성을 더한다 (정합 패턴은 `CPE4R`, 3D F-bar, EAS-TL).
- 종료 기준: 선형 탄성·소변형 소성에서 기존 결과와 동일(회귀 0), 접선 = 내력 야코비안 유한차분(C8형).

### 단계 2 — PSA: 초탄성·점탄성 유한변형 (2D)
- `CPE4H`를 F-bar(`F̄=(J₀/J)^½ F`; 2D 쌍선형 사각형에서 `J̄≡J₀`이므로 중심점 평가로 충분, AGENTS.md §4.16)로 전환. 구성식 호출만 `F̄`, B 연산자는 `F`(§4.17 교훈). 접선은 비대칭이 되므로 `is_numerically_symmetric` 검사(§4.20)와의 상호작용을 시험으로 막는다.
- 점탄성 id 6의 체적 분할 불일치(`K·J(J−1)C⁻¹` vs `K·lnJ·C⁻¹`) 수정. PSA(Arruda-Boyce)는 영향 없으나 신-훅 기저에서 필요.
- 검증: 일축 변형, 단순 전단 수백 %, 등이축, 회전 불변, Rivlin 큐브 (모두 닫힌 형식), Prony 이완 곡선(닫힌 형식).
- 종료 기준: 오차 1% 이내 (변형 0.001~3.0 범위), 단일 요소 NLGEOM 켬·끔.

### 단계 3 — PET: 소성의 정확도 (사용자 우선순위)
단계 0-3, 0-4의 결과에 따라 갈림.
- **분기 A (접힘 변형률이 작아 현행 Hencky가 허용 범위일 때)**: 요소는 그대로 두고 허용 범위(최대 |ln λ|)를 문서화하고, 범위 초과를 경고하는 감시 장치(요소별 최대 국부 신장 > 임계)를 넣는다. 반복 접힘을 위해 `P5`의 이동 경화(Chaboche)를 2D J2에 연결한다 (`plastic_hardening.py`는 있으나 어느 솔버도 읽지 않음).
- **분기 B (허용 범위 초과)**: 소성 요소가 단계 1의 `F_loc`에서 로그 변형률 `ln U`를 직접 만들고(극분해) 곱셈 소성 반환 사상(Simo)과 일관 접선을 쓰게 한다. 오라클은 0-2.
- 어느 분기든: **PEEQ와 소성 변형률 출력**, 제하·재부하·반복 시험, 소성 + 큰 회전 시험(이번에 통과한 시험을 시험 묶음에 영구화).
- 종료 기준: 일축 변형·단순 전단·굽힘 모멘트-곡률이 닫힌 형식과 허용 오차 이내 (허용 오차는 0-4의 곡선에서 정해 문서화).

### 단계 4 — GLASS와 응력 출력
- GLASS는 탄성이므로 변형 척도 선언(선형 탄성 = 현행)을 유지하되, **큰 회전에서의 굽힘 모멘트 정확도**를 롤업 벤치마크로 확인.
- 출력: 현재 형상 기준 Cauchy 응력, 로그 변형률, 최대 주응력(파단 판정). `output/`의 응력 복원이 PK2/Cauchy 중 무엇을 가정하는지 점검 (미조사).
- 종료 기준: 순수 굽힘 롤업(180°, 5층, `benchmark_element/benchmark_pure_moment_rollup.py`)에서 모멘트 이론값 오차 1% 이내를 유지, 최대 주응력이 곡률 이론값과 일치.

### 단계 5 — `CPE4I`(EAS)와 3D 이식
- `CPE4I`는 PET·GLASS의 굽힘 요소로 쓰이는데, 유한변형 EAS는 보강 변형을 F에 넣어야 해서(§4.15 B2와 같은 부류) 위험이 가장 크다. 단계 0~4 결과가 PET·GLASS에 `CPE4I`의 소변형 평가가 충분하다고 나오면 보류하고, 아니면 `CPE4R`(이미 TL) 또는 F-bar 요소로 라우팅한다.
- 3D(`C3D8`, `C3D8R`, `C3D8H`): 단계 1~3을 이식. `C3D8H`의 Hencky→GL 경로(측정 −9.5%)를 F̄ 기반 u-p TL로 교체.

### 단계 6 — 종단 검증
- `compact_4` 2D·3D 접힘 실행: 이동 경화 포함 PET, F 기반 PSA로 모멘트-각도, 층간 슬립 곡선.
- 교차 검증: 레거시 ex12(14층, 90°/측 도달)의 모멘트-각도·슬립과 비교 (레거시는 유한변형 Simo 커널을 쓴다).
- 종료 기준: 두 스택의 모멘트 곡선이 합의 범위(0-3에서 정함) 안, 요소 반전 0, 접선 대칭성 경고 없음.

## 7. 위험

1. **수백 % PSA 전단에서의 수렴**: 응력식을 고쳐도 요소 왜곡·반전으로 수렴하지 않을 수 있다. 단계 2 말미에 단일 요소와 얇은 층 스택으로 먼저 시험한다.
2. **F-bar 접선 비대칭**과 RBE2 응축 경로의 대칭 가정(§4.20).
3. **부분 push-forward / 이중 처리**: F4, B2, B3 계열의 반복 결함. 접선 = 내력 야코비안 유한차분 시험을 모든 단계의 종료 기준에 넣는다.
4. PET 이동 경화(P5)와 이 계획의 단계 3이 같은 J2 코드를 건드린다 → P5 결과 병합 후 단계 3 착수.
5. 조사 보고의 미검증 항목(문헌 절 번호, EAS 비압축 한계 주장)에 설계를 기대지 않는다.

## 8. 사용자 결정이 필요한 것

1. **단계 3 분기**: 단계 0-3 측정 전에 PET을 유한변형(분기 B)으로 갈지, 측정 후 결정(권장)할지.
2. **PSA 요소**: `CPE4H`(F-bar) 한 가지로 가는 것(권장)이 맞는지, `CPE4I`로 PSA도 풀고 싶은지.
3. **우선순위**: PSA(단계 2) 먼저인지, PET(단계 3) 먼저인지. PET이 사용자 우선순위라면 단계 0-2~0-4 → 3을 앞당기고 2를 병행한다.
4. **레거시 오라클 사용 허용**: 레거시 JAX 스택을 검증 기준으로 쓰는 것이 프로젝트 방침과 맞는지 (새 스택으로 수렴시키는 방침이라면 닫힌 형식만 쓴다).

## 9. 이 계획이 주장하지 않는 것

- 수정 후 PSA 수백 % 전단 접힘이 수렴한다는 보장.
- 위 공수 추정의 정확성.
- PET에 유한변형 소성이 필요하다는 결론 (측정 전이며, 필요 없을 수도 있다).
