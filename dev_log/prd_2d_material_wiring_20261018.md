# PRD: 2D 요소가 재료 모델을 실제로 따르게 하기 + 프레임워크 재료 전달

**작성일**: 2026-10-18
**목록 번호**: `abaqus_feature_gap_dispfold_20261018.md` §6 N3, N4
**브랜치**: `feat/p7-restart-orientation` (같은 워크트리 `wht_p7`에서 이어서)
**상태**: 구현 완료 (2026-10-18). `tests/test_plastic_history_2d.py` 31개, `tests/test_cpe4h_linear_reference.py` 3개, `tests/test_dispfold_materials.py` 2개 통과.

## 1. 배경

2D 솔버의 요소 10종 중 재료 모델을 호출하는 것은 `CPE4`(NLGEOM 끔)와 `CPE4I`뿐이다. 나머지는 속성 배열의 E, ν로 선형 탄성만 계산하고, `*PLASTIC`이나 초탄성 재료가 와도 **경고 없이 탄성으로 푼다** (3D에는 `elastic_only` 커널 선언과 거부 규칙이 있는데 2D에는 없다). 폴더블 프레임워크의 `ELEM_CASES_2D`(`solid: CPE4I|CPE4R`, `psa: CPE4H`, `plate: CPE4`)가 정확히 이 요소들이고, `example_disp_fold/ex1_dispfold_teardrop.py`는 재료를 `{"E","nu"}` 사전으로만 솔버에 넘긴다. 즉 지금 프레임워크의 2D 결과는 전 층 선형 탄성 접힘이다.

## 2. 실측 현황 (2026-10-18, 소성 인장-제하 시험, 잔류 반력; 0이면 이력 없음)

| 요소 | NLGEOM 끔 (커널) | NLGEOM 켬 (커널) |
|---|---|---|
| CPE4 | −8.92 (0) 정상 | 0 (5) 무시 |
| CPE4I | −8.92 (1) 정상 | −8.92 (11) 정상 |
| CPE4R | 0 (2) 무시 | 0 (13) 무시 |
| CPE4H | 0 (3) 무시 | 0 (12) 무시 |
| CPE3, CPE6, CPE6M, CPE8, CPE8R | 무시 | 무시 |

초탄성(`NEO HOOKE`)을 20% 일축 변형률로 풀면 닫힌 형식 443.3에 대해 CPE4/CPE4I 343.7, CPE4R 0.013, CPE4H 6.7e6, CPE3 0.005 등, 정상 값을 내는 요소가 없다. (CPE4/CPE4I의 22% 오차는 소변형 평가 한계로 이번 범위 밖, §4.)

## 3. 요구사항

R1. 어떤 2D 커널도 재료를 조용히 무시하지 않는다. 재료 모델을 따르지 못하는 커널은 `elastic_only`로 선언되고, 비선형 재료와 만나면 `NotImplementedError`로 거부된다 (3D와 같은 규칙, 같은 메시지 형식).
R2. 폴더블 프레임워크가 쓰는 요소(`CPE4`, `CPE4I`, `CPE4R`, `CPE4H`)는 NLGEOM 켬·끔 모두에서 재료 모델을 따른다: 소성 이력(제하 후 잔류 응력), 초탄성의 선형화 강성.
R3. 선형 탄성 재료에서는 변경 전과 같은 결과 (기존 2D 요소 계약·벤치마크 테스트 무회귀).
R4. 프레임워크(`ex1`)가 `MaterialSpec`의 전체 정의(PET 탄소성, PSA 초탄성+점탄성, GLASS·PLATE 탄성)를 솔버에 전달하고, 요소 종류도 `ELEM_CASES_2D`대로 쓴다. 솔버가 거부하는 조합이면 조용히 대체하지 말고 알린다.

## 4. 비범위

- 2D 초탄성의 유한변형 정확도. 2D·3D 디스패치는 소변형 `eps`와 `F=I`를 넘기므로 큰 신장에서 닫힌 형식과 어긋난다. 이번에는 측정해 기록만 한다.
- CPE3, CPE6, CPE6M, CPE8, CPE8R, 축대칭(CAX), 트러스의 재료 연결: 선언과 거부로 끝낸다.
- 3D 커널 변경.

## 8. 후속: 나머지 5개 요소도 재료에 연결 (2026-10-18)

- `CPE3`, `CPE6`, `CPE8`, `CPE8R`, `CPE6M`의 커널을 `material_dispatch_2d` 호출로 교체하고 카탈로그에서 `elastic_only`를 해제(커널 6, 7, 8, 9, 10, 14). 이제 2D 평면변형률 요소 9종 전부가 재료 모델을 따른다. 남은 `elastic_only`: 4(CPE4 F-bar), 5(CPE4 co-rotational 탄성 전용), 15~17(축대칭), 18(트러스).
- 발견: `CPE8`/`CPE8R` 커널에는 커널 자체의 **상태 없는 완전소성 J2**가 있었고 `props[2]`, `props[3]`을 항복응력·경화계수로 읽었다. 표형 J2 재료의 `props[2]`는 점의 개수라서, 재료를 통과시켰다면 엉뚱한 항복응력으로 읽혔을 구조다. 평면 부분은 디스패치로 교체(축대칭 분기는 그대로).
- `CPE6M`의 체적 모래시계 상수는 재료의 초기(탄성) 접선의 전단 계수에서 가져온다 (소성 접선 연화로 모드가 풀리는 것을 막음).
- **단일 요소 검증(9개 요소 전부)**, `tests/test_plastic_history_2d.py` 88개:
  1. 소성 기억: 인장 후 제하의 잔류 압축.
  2. **정량 일치**: 일축 변형 J2(선형 등방 경화)의 닫힌 형식으로 유도한 잔류 응력 −8.920 (1차 소성 eₚ=(2μe−σ_y0)/(3μ+H), 제하 중 역항복 a=(3μeₚ−σ_y0−Heₚ)/(3μ+H), σ_xx=−2μ(eₚ−a)). 8개 요소·모드는 1e-6, `CPE4R`은 Green-Lagrange 변형률 때문에 8%, `CPE3`/`CPE6`의 NLGEOM=YES는 2e-3 (일반 co-rotational 래퍼가 쓰는 Kabsch 최적 회전이 절점 배치가 등방적이지 않은 삼각형에서 극분해 회전과 O(변형률) 달라서 2차로 생기는 3.3e-4 차이를 측정).
  3. 초탄성 미소변형 강성: K+4μ/3 (신-훅), 1% 이내.
  4. **큰 회전 객관성**: 5% 소성 신장 후 40° 강체 회전에서 힘이 요소와 함께 회전 (9개 요소, 오차 2e-3 미만). 회전을 2° 스텝으로 쪼개야 한다: 스텝 안에서 변위가 선형 보간되어 큰 증분은 절점을 호가 아닌 현으로 움직여 요소를 찌그러뜨린다.
  5. **접선 = 내력의 유한차분 야코비안** (소성 하중 상태, 초탄성 상태; NLGEOM 끔).
  6. 선형 탄성 회귀, 축대칭 커널의 거부 유지.

## 9. 후속: 소성 굽힘 측정과 두 가지 수정 (2026-10-18)

**측정**: 평면변형률 띠의 순수 굽힘(L=10h, 20×8 요소, 끝단 단면을 ±φ/2 강체 회전으로 처방, NLGEOM 켬, 10스텝)을 코드 밖 numpy 섬유 오라클과 비교. 오라클은 각 섬유를 ε_x=κy, ε_z=0, σ_y=0으로 3D J2 반환 사상(선형 등방 경화)으로 적분해 모멘트를 구한다. 탄성 구간에서 평면변형률 굽힘 강성 E′κh³/12와 3e-5로 일치 (`tests/test_plastic_bending_2d.py`).

| 요소 (κh/2 = 0.5% / 1.2% / 2%, 항복 변형률 1%) | 모멘트 / 오라클 (수정 전) |
|---|---|
| CPE4 (완전적분) | 1.096 / 1.089 / 1.087 (전단 잠김) |
| CPE4H | 1.082 / 1.075 / 1.059 (잠김) |
| **CPE4I** | 1.004 / 0.992 / 1.023, **κ≥1.2%에서 수렴 실패** |
| CPE4R | 1.005 / 1.014 / 1.020 |
| CPE8R | 1.001 / 0.993 / 0.981 |

**수정 1 — `CPE4I`의 보강 변위 α를 평형까지 반복** (`cpe4i_numba.py`). 이전에는 α=0 주변에서 선형 풀이 한 번(`fe = fu − Kua·Kaa⁻¹·fa`)이라 선형 재료에서만 정확했고, 소성에서는 응축된 힘이 요소 에너지의 미분이 아니며 접선이 야코비안과 1.9e-3 어긋났다. 이로 인해 PET 소성 굽힘의 Newton이 마지막 스텝에서 5 → 8 → 38회로 늘다가 실패했다. 이제 `fa(α)=0`까지 Newton 반복(재료는 증분 시작 상태에서 시험 평가, 수렴한 평가만 커밋). 선형 재료에서는 첫 Newton 한 번이 정확하므로 결과 불변.
- 결과: 굽힘 수렴, 모멘트 오라클 2% 이내, 접선 = 내력 야코비안 (소성·초탄성 모두 2e-4 미만), 선형 요소 시험 25개 통과.

**수정 2 — co-rotational 프레임을 변형 구배의 극분해 회전으로** (`cr_generic_2d.py`). 이전에는 절점 구름의 최적 맞춤 각(2D Procrustes)이라서 절점 배치가 등방적이지 않은 삼각형은 균일 신장에서도 회전각이 변형률만큼 0이 아니었다(`Σ dX×dx = (1−λ)M₀₁`). 최소제곱 변형 구배 `F=(Σ dx dXᵀ)(Σ dX dXᵀ)⁻¹`의 극분해 각 `atan2(F10−F01, F00+F11)`로 교체. 정사각형에서는 이전 식과 같고, 2노드 트러스(특이 행렬)는 이전 식으로 폴백.
- 결과: 균일 운동 `x=RUX`에서 프레임이 절점 배치·신장·전단에 상관없이 정확히 R (1e-12). `CPE3`/`CPE6` NLGEOM=YES 닫힌 형식 시험의 허용치가 2e-3에서 1e-6으로 조여졌다.
- 3D `cr_generic_3d._kabsch_rotation`은 같은 성질이 있으나 이번 범위 밖 (C3D4/C3D10/C3D6/C3D20).
